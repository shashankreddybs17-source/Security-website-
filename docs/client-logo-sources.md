The existing ten brochure logos and the client display order remain unchanged.
All replacement files are served locally from `public/assets/hitech/clients/`; no remote images are loaded by the website. The eight existing client-logo thumbnails now use lossless WebP rather than another lossy encoding pass. Client order and layout are unchanged.

Indian Express uses the published SVG paths directly for resolution-independent edges. Allen Solly uses a larger transparent published logo (519 x 232 pixels after trimming empty transparent margins). The KVGB asset uses the 2205-pixel-wide nameplate from its designer's published brand material, reduced to 640 x 153 pixels for display at up to 200 CSS pixels. The previous upscaled news image has been removed.

Subhash Photos now uses the matching color logo extracted from its published anniversary artwork (520 x 175 pixels), replacing the 140-pixel source. Keshav Cement is extracted at native resolution from the company's published annual report (531 x 242 pixels). No raster source was artificially enlarged and no AI generation or sharpening filters were used. Existing raster source detail remains the limit for logos without available vector originals.
